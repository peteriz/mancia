Design diagnosis

Specific where it edits. Generic where it earns trust.

The warm cream panel, vermilion action and near-caret placement fit the job beautifully. But the empty-field-as-“Improve” convention is hidden, whole-document replacement is squeezed into one line, and Settings leads with provider internals instead of readiness.

  1. P1
    Expand the high-stakes confirmation.

    Lead with “Replace entire document?”, keep the size delta, and add Show result / Keep editing.

  2. P1
    Name the default action.

    Show “Improve” beside the arrow; remove the one-item preset menu until it becomes a real choice.

  3. P1
    Turn Settings into a readiness path.

    Shortcut, Accessibility and Copilot first. Move model, path and reasoning under Advanced.

  4. P2
    Raise contrast and recovery quality.

    Deepen the light accent to #C2412C and secondary text to #6E6250; let errors reveal details and offer the right next action. Both fixes are carried into the mocks below.

Placement rule · hybrid

The ribbon keeps one predictable home whenever the menu bar is on screen. A full-screen Space has no strip to occupy, so the lane docks to the host window's top edge instead, inset far enough that the auto-revealing menu bar cannot slide over it. Both cases are drawn at screen scale below.

Rule. If the frontmost window is in a full-screen Space or the menu bar is set to auto-hide → anchor to the window's top edge, inset 28pt. Otherwise → anchor below the menu bar on the display holding the frontmost window. In both cases the panel keeps .canJoinAllSpaces and .fullScreenAuxiliary, which EditPanel.swift already sets today.

Recommendation

Prototype the Command Ribbon. Borrow the Rail’s review gate.

With the inline lens retired, the ribbon is the strongest everyday surface: one predictable home, a keyboard-first command sentence, and no cross-app anchoring risk. The rail earns its weight only when the stakes rise — so adopt its diff-and-confirm pattern as the ribbon’s whole-document review, and keep the full rail as a later document mode. Because both wear the shipped palette, either can graduate to production without a rebrand.

  1. Build the hybrid placement rule first.
    Resolved above: screen-anchored below the menu bar, window-anchored and inset 28pt in a full-screen Space. Verify it against multi-display, Split View and menu-bar auto-hide before anything else is built.
  2. Wire the command sentence for keyboards.
    Tab moves target → action → direction; ⌘1/⌘2 switch scope; Esc always restores the host untouched.
  3. Adopt the rail’s review gate for document edits.
    Diff first, then “Replace entire document?” on the ink block — never a one-line confirmation.
  4. Hold the color line.
    Vermilion only on Run/Replace; status only through applied-green and warm red; light-mode action at #C2412C and secondary text at #6E6250 to clear 4.5:1.
Method: dual independent review — unanchored design assessment + deterministic source/evidence pass; revision 2 applies the reviewer’s cut and recolors both concepts to Palette.swift.
