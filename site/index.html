For short edits, not a new conversation.

Use chat to explore ideas. Use Mancia when the text is in front of you and you want to change it.

Stays with the selection

The ribbon opens below or above a short selection, or beside a tall block. Your text stays visible.

Undo with ⌘Z

Go back to the previous version that Mancia applied. If the field or text changed, Mancia gives you the result to copy and does not paste.

Keeps your clipboard

Mancia puts your clipboard back after each edit. If you copy something while an edit runs, Mancia keeps your copy.

Asks before it sends a document

With no selection, Mancia asks before it reads and sends the whole document. After you approve, the result replaces the document. ⌘Z brings the old version back.

Privacy: no telemetry and no direct AI API calls. Mancia gives your text to the local GitHub Copilot CLI process. That process can send it to GitHub Copilot services.

Mancia is MIT licensed. It is built in Swift for macOS 14 or later and needs GitHub Copilot CLI.
